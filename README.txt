DATA ANALYST PORTFOLIO

Files:
- index.html  -> main website
- style.css   -> design and responsive layout
- script.js   -> mobile menu and footer year
- hero-image.png -> portfolio hero image (if included)
- resume.pdf -> add your resume here
- certificates/ -> create this folder and put certificate PDFs/images here

HOW TO RUN:
1. Keep all files in the same folder.
2. Put your resume in this folder as resume.pdf.
3. Open index.html in a browser.
4. For GitHub Pages, upload the folder contents to a GitHub repository.

CERTIFICATES:
Open index.html and duplicate a certificate card inside the Certifications section.
Replace the certificate name, organization, date, and href with your real certificate file.

PROJECT LINKS:
Replace the # links for View Dashboard and View Screenshots with your actual project/demo URLs.
